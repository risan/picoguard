Upstream servers

picoguard asks these servers for every name it does not block or have in its cache, and sends more queries to the faster ones. Use udp, tcp, tls or https addresses.

    Rewrites

    Answer a name with your own address, such as nas.lan → 192.168.1.10, or with the addresses of another name. *.nas.lan covers every name under nas.lan. Rewrites work before any list, and while blocking is paused.
